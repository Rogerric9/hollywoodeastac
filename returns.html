Return & Refund Policy

Customers may request a return within 30 days of receiving their order.

Return requests are considered on a case-by-case basis. Because many of our products are unique, collectible, autographed, vintage, or one-of-a-kind items, acceptance of a return may depend on the condition of the item and the circumstances of the request.

Returned items must generally be returned in the same condition in which they were received.

Unless the return is necessary because an incorrect or materially misrepresented item was sent, the customer is responsible for return shipping costs.

We recommend using a trackable shipping method and appropriate insurance when returning valuable items.

Once an approved return is received and inspected, the customer will be notified. If the return is accepted, the refund will be issued using the original payment method.

Original shipping charges are generally not refundable unless the return resulted from an error by Hollywood East Autographs & Collectibles.

If an item arrives damaged or you receive an incorrect item, please contact us as soon as possible so that the situation can be reviewed and resolved.

Please contact Hollywood East Autographs & Collectibles before returning any item so that return instructions can be provided.

Questions about returns may be sent to hollyeastac@gmail.com.
